# Lettra

Salon de mots sur le téléphone : recherche de partie, pendule, chevalet, observation.

Le lexique de départ contient des mots courants. Dans Réglages, un fichier de mots peut être importé : il reste sur l’appareil. Ce n’est pas une liste de tournoi, et le salon n’est pas relié à un autre site.

```bash
npm install
npm test
npm run dev
```

Ouvre l’adresse locale sur le téléphone, ou ajoute la page à l’écran d’accueil.
